# 实验报告

## 算法

连续观测 `(x, x_dot, theta, theta_dot)` 分别在 `[-2.4, 2.4]`、`[-3, 3]`、`[-0.5, 0.5]`、`[-2, 2]` 区间均匀量化为 12 个桶，Q 表形状为 `(12, 12, 12, 12, 2)`，超界观测截断至首尾桶。

对状态动作对 `(S_t, A_t)`，采用 on-policy n-step SARSA 目标：

```text
G_t = sum_{k=0}^{m-1} gamma^k R_{t+k+1}
      + 1[t+n < T] * gamma^n Q(S_{t+n}, A_{t+n}),  m = min(n, T-t)
Q(S_t, A_t) <- Q(S_t, A_t) + alpha * (G_t - Q(S_t, A_t))
```

实验一使用 gamma=0.99、alpha=0.20，epsilon 从 1.0 指数衰减至 0.05，时间常数 800；实验二将 alpha 调整为 0.10、衰减常数改为 1500；实验三进一步将 epsilon 改为从 0.5 衰减至 0.01。

安装依赖：

```bash
uv sync
```
运行：

```bash
uv run python discrete_cartpole.py --n-values 1 --seeds 0
```

## 实验设置

共进行三轮实验。三轮实验使用相同的离散化（每维 12 个桶，Q 表形状 \(12^4\times 2\)）和 `gamma=0.99`

| 轮次 | \(n\) 取值 | 训练回合 | 种子数 | 评估回合 | alpha | epsilon | epsilon 衰减 |
|---|---|---:|---:|---:|---:|---|---:|
| 实验一 | 1, 3, 5 | 3000 | 5 | 100 | 0.20 | 1.0 → 0.05 | 800 |
| 实验二 | 3, 4, 5, 6, 7 | 5000 | 5 | 100 | 0.10 | 1.0 → 0.05 | 1500 | 
| 实验三 | 3, 4, 5, 6, 7 | 5000 | 3 | 100 | 0.10 | 0.5 → 0.01 | 1500 |

原始结果保存在 `results/*.csv`。

- \(n=4\) 在训练末 100 回合均值（332.8）和评测均值（386.1）上均为最高，且种子间标准差较小（50.3），是三轮实验中最稳健的设置。

## 分析n的影响
综合三轮结果：
1. 多步回报优于一步 SARSA。 \(n=1\) 的训练和评测回报均明显低于 \(n\ge3\) 的设置。
2. \(n=4\) 是当前最稳健的选择。 实验二中 \(n=4\) 的训练末 100 回合均值最高（283.8）；实验三中 \(n=4\) 的训练末 100 回合均值为 332.8，评测均值为 386.1，种子间标准差为 50.3。两轮 5000 回合实验方向一致。
3. \(n=5\) 波动较大。 实验一、二、三的评测均值分别为 327.9、322.5、288.0，且多次出现单种子接近或超过 475、其他种子明显偏低的情况，稳定性不如 \(n=4\)。
4. \(n=6\)、\(n=7\) 的结果不稳定。 实验二中二者评测均值为 332.9 和 336.2，看似最高；但实验三中 \(n=6\) 降至 221.0、\(n=7\) 降至 284.2。\(n=7\) 的训练末 100 回合均值虽达 329.2，但评测均值明显低于 \(n=4\)。这说明 \(n=6,7\) 的优势未能在不同超参数和种子下复现，不能作为稳定备选。

## 局限

- 种子间方差大。 主要噪声来自训练轨迹的随机性，包括初始状态、探索动作和并列最大 Q 值的随机打破，而非评估回合数不足。
- 超参数在三轮间发生变化。 实验一使用 `alpha=0.20`、epsilon 衰减常数 800；实验二改为 `alpha=0.10`、衰减常数 1500；实验三进一步将 epsilon 从 0.5 衰减到 0.01。因此跨轮比较 \(n\) 时，\(n\) 的影响与超参数变化混杂。实验三的 \(n\) 比较相对最直接，但种子数仅 3 个。
- 种子数不足。 实验一、二为 5 个种子，实验三仅 3 个种子。对于种子间标准差 39–154 的结果，3–5 个种子不足以做统计显著的排序；实验三中 \(n=6\) 的低值可能部分来自种子抽样，需更多种子确认。
- 学习率与探索率仍可能偏大。 实验三中 \(n=4\) 的训练末 100 回合均值为 332.8，距离 500 仍有差距；epsilon 末值 0.01 虽已较低，但训练早期探索和 Q 值更新步长仍会影响收敛稳定性。
- 评估时随机打破平局。 若评估改用确定性 argmax，可降低评估方差，使不同 \(n\) 的比较更可靠。
