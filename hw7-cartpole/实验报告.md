# 实验报告

## 算法

连续观测 `(x, x_dot, theta, theta_dot)` 分别在 `[-2.4, 2.4]`、`[-3, 3]`、`[-0.5, 0.5]`、`[-2, 2]` 区间均匀量化为 12 个桶，Q 表形状为 `(12, 12, 12, 12, 2)`。超界观测截断至首尾桶。

对状态动作对 `(S_t, A_t)`，采用 on-policy n-step SARSA 目标：

```text
G_t = sum_{k=0}^{m-1} gamma^k R_{t+k+1}
      + 1[t+n < T] * gamma^n Q(S_{t+n}, A_{t+n}),  m = min(n, T-t)
Q(S_t, A_t) <- Q(S_t, A_t) + alpha * (G_t - Q(S_t, A_t))
```

超参数初始为 `gamma=0.99`、`alpha=0.20`。episode 结束时用较短回报更新剩余轨迹。epsilon-greedy 探索率从 1.0 指数衰减至 0.05，时间常数为 800 个 episode；并列最大 Q 值随机打破平局。

## 实验设置与复现

安装依赖：

```bash
uv sync
```

运行完整对比（每个 n 使用 3 个种子训练 1500 回合，贪心策略评测 100 回合）：

```bash
uv run python discrete_cartpole.py --n-values 1 3 5 --seeds 0 1 2 --episodes 1500 --eval-episodes 100
```

逐种子的训练末 100 回合均值、评测均值和标准差写入 `results/nstep_cartpole_results.csv`。比较时对同一 n 的三个种子计算均值和标准差，避免单次随机运行造成误判。

## 结果与分析

### 实验轮次说明

在初步实现后，我们进行了三轮实验，用于观察超参数和 \(n\) 的影响：

1. **第一轮（基线）**：\(n=1,3,5\)，训练 3000 回合，5 个种子，评估 100 回合。用于建立 \(n=1\) 的一步 SARSA 基线和初步趋势。
2. **第二轮（调参验证）**：\(n=3,4,5\)，训练 5000 回合，3 个种子，评估 100 回合。用于验证增加训练回合和加入 \(n=4\) 后的效果。
3. **第三轮（主实验）**：\(n=3,4,5,6,7\)，训练 5000 回合，5 个种子，评估 100 回合。作为最终对比 \(n\) 的主要依据。

三组实验均使用相同的离散化（每维 12 个桶，Q 表形状 \(12^4\times 2\)）、\(\gamma=0.99\)、\(\alpha=0.20\)，\(\epsilon\) 从 1.0 指数衰减至 0.05，时间常数为 800 个 episode，评估时使用贪心策略。表中“训练末 100 回合均值”为每个种子训练最后 100 个 episode 的平均回报；“评测均值”为每个种子贪心评估 100 回合的平均回报；“种子间标准差”为同一 \(n\) 下不同种子评测均值的样本标准差。

### 1. 主实验结果（5000 回合，5 个种子）

表 1 汇总了第三轮主实验的跨种子结果。

| \(n\) | 训练末 100 回合均值（跨种子） | 评测均值（跨种子） | 种子间标准差 |
|---:|---:|---:|---:|
| 3 | 220.4 ± 41.1 | 289.7 ± 98.9 | 98.9 |
| 4 | 283.8 ± 18.4 | 310.0 ± 104.8 | 104.8 |
| 5 | 250.0 ± 36.3 | 322.5 ± 112.8 | 112.8 |
| 6 | 265.1 ± 23.9 | 332.9 ± 80.9 | 80.9 |
| 7 | 271.3 ± 30.9 | 336.2 ± 73.5 | 73.5 |

**观察：**

- **\(n=1\) 基线明显最差。** 第一轮 3000 回合下，\(n=1\) 的评测均值为 194.6，训练末 100 回合均值仅 152.5；而同一轮 \(n=3\) 和 \(n=5\) 的评测均值分别为 251.7 和 327.9。增加 \(n\) 后回报传播更快，符合 n-step TD 的预期。
- **\(n=4\) 的训练回报最高且种子间最稳定。** 主实验中 \(n=4\) 的训练末 100 回合均值为 283.8 ± 18.4，标准差最小；第二轮 3 个种子下 \(n=4\) 的评测均值也达到 386.1，是两轮 5000 回合实验中表现最一致的 \(n\)。
- **评测均值随 \(n\) 增大略有上升，但种子间方差很大。** \(n=6\) 和 \(n=7\) 的评测均值最高（332.9、336.2），种子间标准差相对较小（80.9、73.5）；但 \(n=5\) 的种子间标准差高达 112.8，\(n=3\) 也有 98.9。当前 5 个种子下，\(n=6\) 与 \(n=7\) 的均值只差 3.3，远小于种子间标准差，尚不能认为二者有显著差异。
- **单种子达到 475 不代表稳定解决。** 第一轮 \(n=5\) 有一个种子评测 474.71，第三轮 \(n=5\) 有一个种子 490.25，第二轮 \(n=3\) 有一个种子 479.33；但同一 \(n\) 的其他种子常只有 200–350。这说明训练对随机性非常敏感，不能用单次 475 以上的结果宣称“已解决”。
- **训练回报普遍低于评测回报。** 主实验训练末 100 回合均值仅 220–284，而评测均值 290–336。原因是训练时仍保留约 5% 的 \(\epsilon\) 探索，500 步中约 25 次随机动作，足以导致提前失败；评测使用贪心策略，因此回报更高。这也说明训练末 100 回合的回报不能直接与 475 的解决标准比较。

### 2. 训练回合数的影响

对比第一轮（3000 回合）和第三轮（5000 回合）中相同 \(n\) 的结果：

| \(n\) | 3000 回合评测均值 | 5000 回合评测均值 | 3000 回合训练末 100 | 5000 回合训练末 100 |
|---:|---:|---:|---:|---:|
| 3 | 251.7 | 289.7 | 181.2 | 220.4 |
| 5 | 327.9 | 322.5 | 196.1 | 250.0 |

训练回合从 3000 增加到 5000 后，训练末 100 回合均值明显上升（\(n=3\) 从 181.2 到 220.4，\(n=5\) 从 196.1 到 250.0），说明 Q 表仍在学习；评测均值的变化则不单调，\(n=3\) 上升而 \(n=5\) 略降，进一步说明种子间方差掩盖了真实差异。

### 3. \(n\) 的影响分析

- **\(n=1\)（一步 SARSA）**：偏差最大、回报传播最慢，在相同训练量下评测均值最低。作为基线，它验证了多步回报的必要性。
- **\(n=3\)**：相比 \(n=1\) 有明显提升，但在 5000 回合主实验中训练回报和评测均值都低于 \(n=4\)，且种子间方差较大。
- **\(n=4\)**：两轮 5000 回合实验中训练回报最高、种子间标准差最小，是当前最稳定的选择。原因可能是它在“回报传播速度”和“回合末尾短回报更新”之间取得了较好的平衡。
- **\(n=5\)–\(7\)**：评测均值略高，但方差大，且 \(n=5\) 两轮结果不一致（第二轮 288.0，第三轮 322.5）。\(n=6\) 和 \(n=7\) 的种子间标准差相对较小，但均值差异不显著。\(n\) 继续增大时，CartPole 回合长度有限，更多更新依赖回合末尾的短回报，bootstrapping 减少，方差会进一步上升。
- **总体趋势**：从 \(n=1\) 到 \(n=4\) 提升明显；\(n=4\) 到 \(n=7\) 进入平台期，差异小于种子间噪声。当前数据不支持“\(n\) 越大越好”，更合理的结论是 **\(n=4\) 是较稳健的选择，\(n=6\) 可作为备选**。

### 4. 方差来源与局限

- **种子间方差大**：主实验评测均值的种子间标准差为 73–113，而每个种子内 100 回合评估均值的标准误只有约 7–11。主要噪声来自训练轨迹的随机性（初始状态、探索动作、平局随机打破），而不是评估回合数不足。
- **\(\alpha=0.20\) 偏大**：较大的学习率加快了早期学习，但也放大了不同种子收敛到不同策略的可能性，是种子间方差大的重要原因。
- **\(\epsilon\) 衰减时间常数 800**：在 5000 回合时 \(\epsilon\approx0.05+0.95e^{-6.25}\approx0.052\)，训练末仍有约 5% 探索，限制了训练回报上限。
- **平局随机打破**：训练和评估中 Q 值相等时随机选动作，增加了评估方差。评估时若改用确定性 argmax，可降低该噪声。
- **未稳定达到 475 标准**：主实验没有任何一个 \(n\) 的跨种子评测均值接近 475；单种子偶有 475 以上，但不能视为稳定解决。

## 结论

本实验在离散化 CartPole-v1 上实现了表格型 n-step SARSA，并比较了 \(n=1,3,4,5,6,7\) 的效果。主要结论如下：

1. **多步回报优于一步 SARSA。** \(n=1\) 的训练和评测回报均明显低于 \(n\ge3\) 的设置，验证了 n-step TD 通过更快传播回报提升学习效果的预期。
2. **\(n=4\) 是当前最稳健的选择。** 在两轮 5000 回合实验中，\(n=4\) 的训练末 100 回合均值最高（283.8 ± 18.4），种子间标准差最小，评测均值也处于较高水平。
3. **\(n=6\)、\(n=7\) 的评测均值略高，但差异不显著。** 主实验中 \(n=6\) 和 \(n=7\) 的评测均值为 332.9 和 336.2，种子间标准差为 80.9 和 73.5；二者均值差 3.3，远小于种子间噪声，不能认为 \(n=7\) 显著优于 \(n=6\)。
4. **尚未稳定达到 475 的解决标准。** 单种子偶有 475 以上的评测结果，但同一 \(n\) 的其他种子常低至 200–350，说明训练对随机性敏感，不能以单次结果宣称解决。
5. **主要瓶颈是训练方差和探索率，而非 \(n\) 的选择。** \(\alpha=0.20\) 偏大、\(\epsilon\) 在 5000 回合时仍约 5%、评估时平局随机打破，共同导致种子间方差大。后续应优先增加种子数、降低学习率、延长 \(\epsilon\) 衰减时间，并在评估时使用确定性 argmax，再对 \(n=4\) 与 \(n=6\) 做更可靠的对比。

综上，若只选一个 \(n\)，推荐 **\(n=4\)**；若追求更高评测均值且可接受更大方差，可将 **\(n=6\)** 作为备选。当前结果足以说明“多步优于一步、适中 \(n\) 较优”，但还不足以在 \(n=4\) 与 \(n=6\) 之间做出统计显著的取舍。
