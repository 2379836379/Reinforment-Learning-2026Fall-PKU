# DiscreteCartPole：n-step TD 学习实验报告

## 实验目标

在离散化的 `CartPole-v1` 环境中实现表格型 n-step TD 控制（n-step SARSA），并比较不同 n 对学习效果的影响。比较设置为 `n = 1, 3, 5`；其中 n=1 是一步 SARSA 基线。

## 方法

连续观测 `(x, x_dot, theta, theta_dot)` 分别在 `[-2.4, 2.4]`、`[-3, 3]`、`[-0.5, 0.5]`、`[-2, 2]` 区间均匀量化为 12 个桶，Q 表形状为 `(12, 12, 12, 12, 2)`。超界观测截断至首尾桶。

对状态动作对 `(S_t, A_t)`，采用 on-policy n-step SARSA 目标：

```text
G_t = sum_{k=0}^{m-1} gamma^k R_{t+k+1}
      + 1[t+n < T] * gamma^n Q(S_{t+n}, A_{t+n}),  m = min(n, T-t)
Q(S_t, A_t) <- Q(S_t, A_t) + alpha * (G_t - Q(S_t, A_t))
```

超参数为 `gamma=0.99`、`alpha=0.20`。episode 结束时用较短回报更新剩余轨迹。epsilon-greedy 探索率从 1.0 指数衰减至 0.05，时间常数为 800 个 episode；并列最大 Q 值随机打破平局。

## 实验设置与复现

安装依赖：

```bash
uv sync
```

运行完整对比（每个 n 使用 3 个种子训练 1500 回合，贪心策略评测 100 回合）：

```bash
uv run python discrete_cartpole.py --n-values 1 3 5 --seeds 0 1 2 --episodes 1500 --eval-episodes 100
```

逐种子的训练末 100 回合均值、评测均值和标准差写入 `results/nstep_cartpole_results.csv`。比较时对同一 n 的三个种子计算均值和标准差，避免单次随机运行造成误判。
