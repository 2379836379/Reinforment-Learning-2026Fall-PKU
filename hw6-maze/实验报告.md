# Dyna-Q 与 Dyna-Q+ 迷宫实验

## 1. 实验目的

在 Maze 环境中实现 Dyna-Q 和 Dyna-Q+，并观察环境发生 Blocking 或 Shortcut 变化后，两种算法重新发现路径的能力。

## 2. 算法实现

每个真实交互步骤都进行一次 Q-learning 更新，然后从已经访问过的状态-动作对中随机抽取 `n=20` 次进行 planning。planning 转移直接调用 `MazeEnv`，因此不需要额外维护环境模型。

Dyna-Q+ 在 planning 更新中加入探索奖励：

\[
r^+ = r + \kappa\sqrt{\tau}, \qquad \kappa=10^{-4}
\]

其中 `tau` 是该状态-动作对距离上次真实尝试经过的时间步数。学习率 `alpha=0.1`、折扣率 `gamma=0.95`、epsilon-greedy 的 `epsilon=0.1`。每个实验运行 1000 个 episode，并在第 500 个 episode 改变迷宫。

## 3. 环境设置

- Blocking Maze：在第 500 个 episode 将 `(3,0)` 和 `(3,1)` 设置为墙，阻断原来的上方路线。
- Shortcut Maze：在第 500 个 episode 打开 `(7,1)` 和 `(7,2)`，形成通往目标的新路线。

episode 长度按改变环境前后分别求平均。程序中的 `MazeEnv::set_wall` 支持运行时修改墙体，planning 后会恢复真实交互状态。

## 4. 运行结果

一次固定随机种子运行得到：

| 环境与算法 | 变化前平均步数 | 变化后平均步数 |
| --- | ---: | ---: |
| Blocking Dyna-Q | 17.092 | 15.862 |
| Blocking Dyna-Q+ | 24.540 | 15.698 |
| Shortcut Dyna-Q | 17.092 | 13.962 |
| Shortcut Dyna-Q+ | 24.540 | 13.612 |

Dyna-Q 能通过 planning 快速传播新路径的价值；Dyna-Q+ 对长期未尝试的状态-动作对给予额外奖励，因此在环境发生变化后更倾向于探索旧策略没有覆盖的区域。本次单次运行中 Dyna-Q+ 的前期平均步数较高，属于探索奖励带来的额外探索成本；多次随机种子运行时应报告均值和标准差。
