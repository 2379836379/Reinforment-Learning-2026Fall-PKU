# Windy Gridworld 作业报告

## 任务概述

本作业基于 Sutton《Reinforcement Learning》例 6.5 的 Windy Gridworld，实现 SARSA 和 Q-Learning 两种时序差分控制算法。环境为 10 x 7 网格，起点为 `(0,3)`，终点为 `(7,3)`；每执行一个动作得到奖励 `-1`，各列风力由题目给定。

## 算法描述

两种方法均维护动作价值函数 `Q(s,a)`，行为策略采用 epsilon-greedy：以概率 `epsilon=0.1` 随机选择动作，否则选择当前 Q 值最大的动作。学习率为 `alpha=0.5`，折扣因子为 `gamma=1.0`，训练 1,000,000 个回合。

### SARSA

SARSA 是 on-policy 方法。环境执行当前 epsilon-greedy 动作 `a` 后，在下一状态 `s'` 继续依据同一 epsilon-greedy 策略选出 `a'`，并按下式更新：

```
Q(s,a) <- Q(s,a) + alpha * [r + gamma * Q(s',a') - Q(s,a)]
```

到达终点时没有下一动作，更新目标仅为即时奖励 `r`。

### Q-Learning

Q-Learning 是 off-policy 方法。行为仍使用 epsilon-greedy 探索，但更新时采用下一状态的最大动作价值：

```
Q(s,a) <- Q(s,a) + alpha * [r + gamma * max_a' Q(s',a') - Q(s,a)]
```

同样地，到达终点时更新目标仅为即时奖励。

## 实验结果

使用 `g++ -std=c++11 -Wall -Wextra -pedantic windygridworld_main.cpp` 编译并运行后，两种算法均得到如下贪心路径：

```
(0,3)->(1,3)->(2,3)->(3,3)->(4,4)->(5,5)->(6,6)->(7,6)->(8,6)->(9,6)->(9,5)->(9,4)->(9,3)->(9,2)->(8,2)->(7,3)
```

SARSA 和 Q-Learning 的 episode length 都为 **15**，满足题目中“不超过 17 步”的要求。
