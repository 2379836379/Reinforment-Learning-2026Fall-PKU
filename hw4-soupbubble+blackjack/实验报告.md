# HW4 SoupBubble + Blackjack 实验报告

## 1. 实验目的

实现 Sutton《Reinforcement Learning》中的两个蒙特卡洛示例：用随机游走估计肥皂泡内部高度，用带 exploring starts 的蒙特卡洛策略迭代学习 Blackjack 玩家策略。

## 2. SoapBubble

### 算法

对每个非边界网格点独立进行 `iter` 次随机游走。每一步从当前点的所有内部邻居中等概率选择一个邻居，直到到达边界；将终止边界点的高度作为本次样本回报。内部点高度取所有回报的平均值：

```text
V(x) = E[边界点高度 | 从 x 开始的随机游走]
```

这是离散 Laplace 方程的蒙特卡洛估计，与程序中的动态规划更新使用同一组内部邻接点。

### 结果

运行 `soapbubble_main.cpp` 会依次输出初始网格、动态规划结果和蒙特卡洛结果。以默认 `10 x 10` 网格和 `500000` 次采样运行时，蒙特卡洛内部值与动态规划值的差异在显示精度内，满足题目要求的 `±0.05`。

## 3. Blackjack

### 算法

状态使用 `(dealer_shown, player_usable_ace, player_sum)` 表示，动作是 `HIT` 或 `STICK`。Dealer 遵循固定策略：点数小于 17 时 Hit，否则 Stick。

每次策略评估遍历所有明牌、usable ace、玩家点数（11--20）和玩家首动作，调用 `Blackjack::reset` 构造 exploring start。之后玩家按照当前策略行动，Dealer 按默认策略行动，直到终局。由于非终止步骤奖励为 0，终局的玩家奖励就是该回合所有玩家状态-动作的回报；用增量平均更新 `Q(s,a)`。

策略改进对每个状态比较 `Q(s,HIT)` 和 `Q(s,STICK)`，选择估计值较大的动作；点数 21 固定为 Stick。主程序重复策略评估和改进 10 次，再打印最终策略。

## 4. 运行与结果

编译命令：

```bash
g++ -std=c++11 -O2 -Wall -Wextra -pedantic soapbubble_main.cpp -o soapbubble
g++ -std=c++11 -O2 -Wall -Wextra -pedantic blackjack_main.cpp -o blackjack
```

Blackjack 输出的每一行对应玩家点数 `21,20,...,11`，每行左侧为无 usable ace，右侧为有 usable ace；每组 10 个字符对应 Dealer 明牌 A--10，`H` 为 Hit，`S` 为 Stick。典型输出形状如下（蒙特卡洛采样会使临界状态偶尔出现一个字符差异）：

```text
Player Without Ace                 Player With Usable Ace.
SSSSSSSSSS                         SSSSSSSSSS
SSSSSSSSSS                         SSSSSSSSSS
SSSSSSSSSS                         SSSSSSSSSS
SSSSSSSSSS                         HSSSSSSSHH
SSSSSSSSSS                         HHHHHHHHHH
HSSSSSHHHH                         HHHHHHHHHH
HSSSSSHHHH                         HHHHHHHHHH
HSSSSSHHHH                         HHHHHHHHHH
HSSSSSHHHH                         HHHHHHHHHH
HHHSSSHHHH                         HHHHHHHHHH
HHHHHHHHHH                         HHHHHHHHHH
```

该结果与 Sutton 书中 Figure 5.2 的最优策略形状一致：硬 17 及以上通常 Stick，硬 12--16 根据 Dealer 明牌选择 Hit/Stick，usable ace 状态在较高点数仍倾向 Hit。

## 5. 结论

两个程序均完成了题目要求的蒙特卡洛估计。SoapBubble 的随机游走估计收敛到动态规划解；Blackjack 的策略迭代通过 exploring starts 覆盖所有状态-动作并逐步改进策略。
