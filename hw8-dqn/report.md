
# CartPole DQN 调整记录

## 网络结构

将原来的单隐藏层网络 `4 -> 64 -> 2` 调整为 `4 -> 128 -> 128 -> 2`，每个隐藏层后使用 ReLU 激活函数。增加隐藏层宽度和深度，可以提升 Q 函数对 CartPole 状态与动作价值关系的拟合能力。

## 训练超参数

| 参数 | 原设置 | 调整后 |
| --- | ---: | ---: |
| 环境 | `CartPole-v0` | `CartPole-v1` |
| 学习率 | `1e-3` | `3e-4` |
| 折扣因子 `gamma` | `1.0` | `0.99` |
| 初始探索率 `epsilon` | `0.02` | `0.20` |
| 最小探索率 | - | `0.01` |
| 探索率衰减 | - | 每回合乘以 `0.995` |
| 经验池容量 | `1000` | `10000` |
| batch size | `32` | `64` |
| 训练回合数 | `1000` | `500` |

初始探索率提高到 `0.20`，避免训练早期过早陷入单一策略；每回合衰减探索率，后期逐渐转向利用当前 Q 网络。经验池扩大后，采样到的状态转移更加丰富；较小的学习率和 `gamma=0.99` 有助于使训练更新更稳定。

## 运行与结果查看

使用以下命令运行训练：

```bash
uv run python dqn_train.py
```

训练完成后，程序会绘制训练回报和测试回报曲线，并保存为 `cartpole_training.png`。`train` 曲线表示每个训练回合的累计回报，`test` 曲线表示每 10 个回合使用贪心策略进行测试的累计回报。`CartPole-v1` 的单回合最高回报为 500。

本次调整后的 `CartPole-v1` 训练已完整运行 500 回合并正常退出；运行过程中未出现 Gymnasium API、张量维度或损失计算错误。

## Target Network

原实现使用同一个在线 Q 网络同时计算 `Q(s, a)` 和下一状态的目标值 `max Q(s', a')`。在线网络在每次反向传播后都会更新，因此训练目标也持续变化，容易造成 Q 值估计震荡，表现为测试回报在较高值后突然下降。

现增加一个与在线网络结构相同的目标网络：初始化时从在线网络复制参数；训练时在线网络用于计算 `Q(s, a)` 并参与反向传播，目标网络只在 `torch.no_grad()` 下计算下一状态最大 Q 值。每完成 500 次梯度更新后，将在线网络参数同步到目标网络一次。

| 参数 | 设置 |
| --- | ---: |
| `target_update_freq` | 500 次梯度更新 |

这种定期硬同步让 Bellman 目标在一段更新期间保持相对固定，有助于降低训练震荡、提高测试回报的稳定性。
