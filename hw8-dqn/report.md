# DQN 实验报告

## CartPole

将 CartPole 使用的 MLP 从原单隐藏层结构 4→64→2 调整为两层隐藏层结构 4→128→128→2。实验按顺序进行三个单因素对照，每个配置运行 1000 回合、使用 3 个训练种子。学习率和网络宽度沿用实验选出的配置。 

| 对照 | 配置 A 的后期验证均分 | 配置 B 的后期验证均分 |
| --- | :---: | :---: |
| 初始 epsilon：0.20 vs 1.0 | 201.55 ± 55.63 | 116.27 ± 56.46 |
| 学习率：3e-4 vs 5e-4 | 201.55 ± 55.63 | 253.60 ± 56.91 | 
| 隐藏层：64×64 vs 128×128 | 217.68 ± 93.81 | 253.60 ± 56.91 | 

在初始 epsilon 对照中，0.20 的后期验证均分为 201.55 ± 55.63，高于 1.0 的 116.27 ± 56.46，说明在该小规模对照中提高初始探索率并未改善平均表现，因此后续保留 epsilon=0.20。在学习率对照中，5e-4 的后期验证均分为 253.60 ± 56.91，比 3e-4 的 201.55 ± 55.63 高 52.05 分，但种子间差异仍然明显。在网络宽度对照中，128×128 的后期验证均分为 253.60 ± 56.91，高于 64×64 的 217.68 ± 93.81，且种子间标准差更小。

## Breakout

### 算法与训练设置
Breakout 的输入改为四帧灰度图像堆叠，并使用 32/64/64 通道的卷积编码器。卷积特征之后增加 Dueling 价值/优势双分支，每个分支为 256 单元。

Breakout 配置加入目标网络，每 1000 次梯度更新硬同步、Double DQN、Huber loss 和全局梯度范数裁剪；预热从 1000 步提高至 10000 步，epsilon 从 1.0 到 0.1 的线性衰减计划从 100000 步延长至 250000 步，学习率从 1e-4 调整为 5e-5。优化版在统一的 20 局测试中均分为 6.80；最佳模型（第 350 回合）均分为 10.65。早期原版最终模型均分为 1.35，显示优化版优于原版最终模型。

### 策略

对不同策略进行100局评估，均值如下：

| 策略 | epsilon=0.01 | epsilon=0.05 |
| --- | ---: | ---: |
| 1-step 最终模型 | 6.76 | 5.87 |
| 1-step 最佳模型（第 350 回合） | 11.71 | 10.23 |
| 3-step 最终模型 | 4.94 | 4.34 |
| 学习率 2.5e-5 最终模型 | 3.08 | 3.43 |
| 固定 LEFT | 10.90 | 10.60 |
| 均匀随机动作 | 1.27 | 1.27 |
| 固定 NOOP / RIGHT | 0.00 / 0.04 | 0.01 / 0.04 |

固定 LEFT 在当前无随机开局环境中是很强的简单策略。1-step 最终模型、3-step 最终模型和低学习率最终模型均没有超过它。1-step 第 350 回合最佳模型在 epsilon=0.01 下略高于 LEFT，但在 epsilon=0.05 下低于 LEFT。部分实验的验证最佳 checkpoint 落在第 50 回合，梯度更新次数为零，早期高分来自初始化网络在当前固定开局上的行为。

### 调整算法和超参数

以 1-step 模型作为参照调整算法和超参数：

| 调整 | 设置 | 末 100 回合训练均分 | 最后五次验证均分 | 最终 20 局均分 | 结论 |
| :---: | :---: | :---: | :---: | :---: | :---: |
| 1-step 参照 | lr=5e-5，185499 步，43875 次更新 | 3.15 | 5.56 | 6.80 | |

| 3-step 回报 | n=3，198194 步，47049 次更新 | 3.47 | 4.56 | 5.00 | 训练末段均分略高，但验证与最终测试低于 1-step。 |
| 学习率减半 | lr=2.5e-5；170052 步，40014 次更新 | 1.74 | 1.14 | 3.20 | 比 5e-5 参照差 |

### 总结
综合来看，优化版相对原版最终模型有提升，但最终模型未稳定超过固定 LEFT；延长训练、3-step 回报和降低学习率均未显示稳定收益。训练不稳定和曲线回落问题仍未消除。
